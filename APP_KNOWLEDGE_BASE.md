# База знаний приложения: Harmonic & Voice-Leading Engine

## 1. Введение и архитектура
Данное приложение — это алгоритмический движок для обучения классической гармонии (4-голосие SATB).
- **Стек:** React, Vite, TypeScript, Express (API routes).
- **Ключевые модули:** 
    - `src/audio/`: Аудиодвижок (аддитивный синтез) и логика гармонизации.
    - `src/utils/spacedRepetition.ts`: Алгоритм интервальных повторений для обучения.
    - `src/components/`: Интерфейсы, VexFlow нотация, модальные окна настроек.
    - `src/db/`: Слой хранения данных.

## 2. Музыкально-теоретические основы
Движок базируется на правилах классической гармонии (Способин, Римский-Корсаков):
- **Представление высот:** MIDI (0-127).
- **SATB фактура:** 4 голоса с жесткими регистрами (B, T, A, S).
- **Проверка голосоведения:** Анализатор запрещает параллельные квинты/октавы, перекрещивания голосов, некорректные скачки.
- **Оптимизация:** Алгоритм ветвей и границ для плавного голосоведения (минимизация перемещений).

## 3. Основные функциональные движки
- **AudioEngine (`audioEngine.ts`):** Web Audio API, аддитивный синтез обертонов, реалистичный тембр рояля без сэмплов (ADSR огибающая).
- **HarmonizationEngine (`harmonizationEngine.ts`):** Детерминированное построение SATB, проверка ошибок, Branch-and-Bound солвер.
- **ProgressionDatabase:** 164 академических оборота (разбиты на 10 классов, от простых каденций до альтерированных созвучий). База в `HARMONIC_PROGRESSIONS_DATABASE.json`.

## 4. Спецификации и данные
Для работы других ИИ-ассистентов с кодом:
- **API:** Серверная часть в `server.ts`.
- **Данные:** Используйте `HARMONIC_PROGRESSIONS_DATABASE.json` для всех операций с гармоническими оборотами.
- **Алгоритмы:** Строго следуйте формулам транспонирования (`TonicPitch + satbOffsets`) из `PROGRESSIONS_REFERENCE_MANUAL.md`.

## 5. Инструкция для ИИ-коллег
1. **Анализ:** При анализе задач студента сверяйте результаты с `satbOffsets` и академическими правилами из `MUSIC_ENGINE_SPECIFICATION.md`.
2. **Модификация:** Любые изменения в гармонической логике требуют обновления `MUSIC_ENGINE_SPECIFICATION.md`.
3. **Безопасность:** Не меняйте правила голосоведения без согласования (академический стандарт).
4. **Контекст:** Всегда учитывайте ладовые тяготения (T, S, D, M функции).
